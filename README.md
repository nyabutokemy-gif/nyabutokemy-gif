## 📊 Featured Project

### 🚲 Cyclistic Bike-Share Analysis

An end-to-end data analytics project investigating how **annual members and casual riders use Cyclistic differently** and how Cyclistic could encourage casual riders to become members.

**5.9M+ rides analysed**

**Tools:** Python · SQL · Tableau

**Project workflow:**

`Data Cleaning → Python Analysis → SQL → Tableau → Business Recommendations`

**Key findings:**
- Members accounted for approximately **64% of rides**
- Casual riders had substantially longer average rides than members
- Member and casual riders showed different usage patterns across the week
- Seasonal and time-of-day patterns provided opportunities for targeted marketing
