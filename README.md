## 📊 Featured Projects

### 💳 Credit Risk Analysis — SQL & Python

Analysed **150,000 borrower records** to identify characteristics associated with serious delinquency and develop a simple borrower risk segmentation.

**Tools:** SQL · Python · Pandas · NumPy · Matplotlib · SQLite · Google Colab

**Project workflow:**

`Data Quality Assessment → SQL Analysis → Python Cleaning → Visual Analysis → Risk Segmentation → Business Recommendations`

**Key findings:**
- Prior payment history was the strongest indicator of serious delinquency
- Previous 60–89 day and 90+ day late payments were associated with substantially higher risk
- Higher revolving credit utilisation was associated with increased delinquency
- Younger and lower-income borrowers showed higher observed delinquency rates
- Credit exposure variables showed important non-linear relationships
- A rule-based segmentation identified:
  - **High Risk:** 59.82% delinquency rate
  - **Moderate Risk:** 9.94%
  - **Lower Risk:** 3.02%

### 🚲 Cyclistic Bike-Share Analysis

An end-to-end data analytics project investigating how **annual members and casual riders use Cyclistic differently** and how Cyclistic could encourage casual riders to become members.

**5.9M+ rides analysed**

**Tools:** Python · SQL · Tableau

**Project workflow:**

`Data Cleaning → Python Analysis → SQL → Tableau → Business Recommendations`

**Key findings:**
- Members accounted for approximately **64% of rides**
- Casual riders had substantially longer average rides than members
- Member and casual riders showed different usage patterns across the week
- Seasonal and time-of-day patterns provided opportunities for targeted marketing
